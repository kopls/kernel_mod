# Модули ядра Linux

Немного модулей ядра для версии 7.0.3

- **mod_01** — загрузка и выгрузка модулей, параметры и callbacks.
- **mod_02** — настройка параметров через sysfs и установка через DKMS.
- **mod_03** — работа с массивом через параметры модуля.
- **mod_05** — стек с управлением через sysfs.
- **mod_06** — очередь на kfifo с управлением через sysfs.
- **mod_07** — блочный аллокатор памяти с битовой картой.
- **mod_08** — сравнение spinlock, mutex и semaphore в потоках ядра.
- **char_device** — символьное устройство с чтением, записью, ioctl и статистикой в /proc.
